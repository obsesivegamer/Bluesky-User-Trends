# Data: sources, credits and terms

The files in this folder are generated by `updateData.js` (see `docs/ARCHITECTURE.md` for the format):

| File | What it is |
|---|---|
| `bluesky-daily.csv` | The downloadable dataset: one row per UTC day since 2022-11-17. |
| `bluesky-data.js` | The same rows as the page loads them (`window.BLUESKY_DATA`). |
| `users-samples.json` | The timestamped user-count readings the daily series is built from. |
| `sources/plc-rate-samples.json` | PLC directory account-creation rates, used only to shape the 2024 gaps. |

The data is derived from the sources below and stays under their terms. If you reuse it, credit them.

## Sources

- **Jaz's Bluesky index** ([bsky.jazco.dev/stats](https://bsky.jazco.dev/stats), by
  [@jaz.bsky.social](https://bsky.app/profile/jaz.bsky.social), code at
  [jazware/bsky-experiments](https://github.com/jazware/bsky-experiments)): every activity column
  (`dau`, `posters`, `likers`, `followers`, `blockers`, `posts`, `likes`, `follows`, `blocks`), the
  current user count, and the user counts relayed by the archives below. No license is published for
  this data; it is used with credit.
- **Wikimedia Commons, ["Bluesky Registered Users.svg"](https://commons.wikimedia.org/wiki/File:Bluesky_Registered_Users.svg)**
  by VintageNebula, with data gathered by Jaz and Martin Kleppmann et al.
  ([arXiv:2402.03239](https://arxiv.org/abs/2402.03239)), licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It is the source of the `users` column
  from 2022-11-17 to 2024-07-01 (`users_source` = `commons`, and the `interp` rows of that period).
  **Changes made here:** the once-a-day values are assigned to the end of each UTC day, the dates the
  series itself interpolates (2024-02-04 → 07 and 2024-06-23 → 28) are replaced by values
  re-interpolated from other archives, and the series is merged with the sources below.
- **[@hourlybskyusers.bsky.social](https://bsky.app/profile/hourlybskyusers.bsky.social)** by
  [@jordan.weatherby.io](https://bsky.app/profile/jordan.weatherby.io): hourly posts of Jaz's user count.
- **Wayback Machine** captures of `bsky-search.jazco.io/stats`.
- **[Krekeny/bluesky-stats](https://github.com/Krekeny/bluesky-stats)**: daily user counts used to
  fill gaps. MIT License, Copyright (c) 2025 Krekeny. The license notice is reproduced below.
- **[elaval/bskyusers](https://github.com/elaval/bskyusers)**: hourly user counts used to fill gaps
  (no license file; used with credit).
- **[PLC directory](https://plc.directory)**: account-creation rates, used only to shape the user
  curve between known counts in July–November 2024 (`users_source` = `plc-shaped`).
